# Pruebas

Este directorio contendrá las pruebas de la base de datos, incluyendo pruebas
de integridad referencial, restricciones, índices y comportamiento del
esquema.

Las pruebas futuras deberán poder ejecutarse de forma reproducible y reflejar
el esquema aprobado. Por ahora no se han incorporado archivos de pruebas.

No deben almacenarse aquí migraciones, scripts operativos, respaldos,
secretos, archivos de entorno ni resultados temporales generados por las
pruebas.
