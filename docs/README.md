# Documentación

Este directorio contiene la documentación técnica específica de la base de
datos, las decisiones de diseño y los procedimientos de despliegue de VIGIA.

Aquí se almacenarán documentos Markdown u otros documentos técnicos que
describan el esquema aprobado, sus decisiones y sus procedimientos asociados.

No deben almacenarse aquí migraciones SQL, scripts ejecutables, respaldos,
secretos ni documentación general de la aplicación que no sea específica de
la base de datos.
