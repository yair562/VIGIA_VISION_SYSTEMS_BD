# Migraciones

Este directorio contendrá las migraciones SQL versionadas e incrementales del
esquema PostgreSQL.

Las futuras migraciones deberán ser trazables, ordenadas y coherentes con el
DDL vigente de trabajo. Por ahora no se han incorporado archivos de migración.

No deben almacenarse aquí scripts operativos, respaldos, archivos de entorno,
secretos ni documentación que corresponda a `docs/`.
